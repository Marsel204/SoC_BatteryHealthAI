# Offline battery analysis pages

Open any HTML file directly in a browser:

| Page | Purpose |
|---|---|
| [English explainer](index.html) | Raw processing through analysis, with worked cycles and interactive figures |
| [Penjelasan Bahasa Indonesia](index-id.html) | Penjelasan lengkap, label grafik dan glosarium dalam Bahasa Indonesia |
| [Audit report](report.html) | Interactive exploratory report |
| [Clustering](clustering.html) | Similar cycles, related features and sensitivity controls |
| [Scatterplots](scatterplots.html) | Nine features against SoH, with Pearson and Spearman statistics |
| [Learning lab](learning/index.html) | Six interactive lessons on statistics and data preparation |

The pages embed their data, scripts and fonts. Each explainer can be shared as one
file and works without a server or internet connection. Links to supporting files
need the surrounding repository layout; the learning lab is also self-contained.

Saved tables and written findings are in [Reports](../../Reports/README.md).
Editable sources and rebuilding commands are in
[Code/analysis](../../Code/analysis/README.md). The live two-step Data analysis →
Model application is documented in [Code/app](../../Code/app/README.md).
