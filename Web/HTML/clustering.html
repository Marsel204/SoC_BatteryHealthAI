Check separation before trusting a grouping

Which features carry a similar pattern?

The tree groups strong relationships, including features that move in opposite directions. The heatmap keeps their direction visible.

Spearman ρ: blue = inverse (−1); neutral = weak (0); orange = same direction (+1). Rows and columns use the same numbered features. Select a square for details.

Tree distance = 1 − |ρ|, averaged between groups. A shorter merge means a stronger shared pattern; sharing a group does not make measurements interchangeable.
