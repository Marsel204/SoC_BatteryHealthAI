What these results suggest
  • t_cc and dq_dv_peak are strong candidates for further validation, but they also correlate strongly with each other (ρ +0.932 to +0.996). Test their additional value later.
  • Some association reflects shared aging trends. For consecutive changes, correlations fall to +0.075–+0.361 for t_cc and +0.475–+0.633 for dq_dv_peak. These diagnostics answer a different question and can amplify noise.
  • rest_time_hours has an inconsistent association and includes charging time. Reconstruct actual idle rest before interpreting it physically.
  • Peak amplitude remains strongly associated with capacity using 5, 10 and 20 mV voltage bins. Peak location is more sensitive to extraction settings.
  • B0006 reaches 101.26% SoH using rated 2 Ah capacity as the denominator. Those values are retained.

The raw files contain 636 discharge records. The source loader excludes the first discharge of each cell, leaving 632. The original CSV was reproduced from the raw files and source code. The primary version masks four charge features when original t_cc < 100 s or original dq_dv_peak < 0.1 Ah/V, using the source screening thresholds. It preserves all cycle rows and labels and applies no interpolation.

Six non-finite sensor values occur in one extra B0018 charging operation that the loader does not select for any aligned cycle. Sensor arrays in the selected charge/discharge records are finite and have matching lengths and increasing sample times. No raw sensor values were repaired.

The prior-EIS alternative uses the latest sweep starting by charge completion; earlier sweeps do not exist for 57 rows. Even a past start does not prove the sweep had completed, because EIS end timestamps are unavailable here. This is a timing diagnostic.

All four batteries were explored. None is an untouched test set after feature decisions based on this report. Only four independent cell trajectories are available. Cycles are temporally dependent, so naive row-level p-values and confidence intervals are omitted. Operating conditions are exported but have not been adjusted for in a multivariable analysis.
